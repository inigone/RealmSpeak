inigone-local changes
=====================
Lists all IL-specific changes in reverse order (newest first).
MERGED UPSTREAM and OBSOLETE tags are omitted — those are upstream changes, not inigone additions.
Update this file before creating each new IL-commit tag.

UPDATER:

BUGS/ISSUES:
